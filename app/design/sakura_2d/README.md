# Sakura 2D concept

Original raster concept produced by `app/scripts/paint_sakura_concept.py` using Pillow and aggdraw; no AI model used. Open `sakura_2d.ora` in Krita to edit five layers: filigree, branches, leaves, flowers, and drifting petals. Save as `.kra` for further Krita work.

`frame_sakura_2d.png`: transparent 1024px source export. Runtime `assets/cosmetics/frame_sakura.png`: 768px. The center is transparent; the existing Shop item, ownership and price stay unchanged.

The Blender expansion script can overwrite the runtime PNG. Re-run the 2D script after Blender rendering to restore this concept.
